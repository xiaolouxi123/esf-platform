# Critique · ESF 平台（启动器全站）

**Provenance**: Assessment A（设计评审，隔离子代理）＋ Assessment B（detector + 定量审计，隔离子代理），本文合并两者。Detector：`detect.mjs --json src` exit 2，13 findings（12 warning / 1 advisory）。Browser overlay：本目标为 Electron 桌面应用，无可用 CDP 会话做 DOM 注入，未生成用户可见 overlay；改用 6 张应用内截图（1320×900）与源码证据。未降级（两个 assessment 均为独立上下文）。

## Design Specificity Verdict

**内容原创，结构换皮。**

原创的是产品事实：中文地图注册表（maps.js:24-104）、五级角色与头衔、约战胜负条件、A2S 延迟、一次性连服 token、成员栏的权限语法。这些换成任何游戏平台都不成立。

换皮的是骨架：登录页＝左营销右表单＋三条 bullet（LoginPage.jsx:119-157）；内页＝暗玻璃＋橙色胶囊导航（App.css:7097-7103）＋hero 大图＋三个 HUD 数字＋常驻成员栏。hero 最露馅：标题是地图名，背景却是全站唯一一张 bg.jpg（App.css:7217-7227）——它在解释"这个产品很燃"，而不是"现在这场怎么进"。

Detector 侧同样指向"模板感"：gradient-text ×7（App.css:3837/4166/4723/4734/4943/7311/8000）、layout-transition ×3（3680/3749/5449）、bounce-easing 1（tokens.css:84）。这些正是"用效果代替结构"的痕迹。

## Overall Impression

**团队会做界面，但没人决定这一屏该说哪句话。**

首屏有两个"去"：橙色的「开始游戏」其实绑定本地开图（Lobby.jsx:1507-1515），把你送进单人空图；真正 4/12 人的对局，是表格里一个 ghost 小按钮。第一格漏斗就是死路，"2 分钟开赛"的承诺因此不可达。

最大机会：hero 的主语从"地图"换成"人"——今晚人最多的房间当主角，主 CTA 是「进入比赛」，本地开图降为次级。

## What's Working

- **地图语言**：中文名＋分类（猿影森林/ape_forestshadow）成了资产；「找到 hl.exe 了，但没找到 esf 模组文件夹」（Lobby.jsx:661-667）是全项目最好的错误文案——说清了发现什么、缺什么。
- **聚焦态**：RankedPage.jsx:554 写明匹配后只留对局卡，实现里只剩服务器、两队、准备数，信息减法做对了。
- **权限语法**：成员栏四组＋等级徽章＋右键改头衔（MemberSidebar.jsx:318-388），把社区层级画了出来，这是产品身份的一部分。

## Priority Issues

### [P0] 主 CTA 动词错：把"进人"做成了"进图"

- **What**：hero 最大、最橙的按钮「开始游戏」触发本地开图（Lobby.jsx:670-698 传给 launch.local；:1507-1515 渲染），玩家进入单人地图后要自己退出来找房间。
- **Why**：新玩家第一动作就失败；老玩家每次都要绕过它。约战/匹配两条路径都被这个按钮盖住，直接破坏成功定义（登录→匹配→开打→结算）。
- **Fix**：hero 主语改为"在线房间"，主按钮「进入比赛」绑定当前人最多/收藏的房；「本地开图」降为 ghost，移入地图卡菜单；匹配入口保留在开赛台。
- **Suggested command**: `/impeccable shape`

### [P1] 结算只结"这一场"，没有"这一轮"

- **What**：RankedResultModal 给单场比分、rating 前后值与 ±delta（RankedResultModal.jsx:86-93），但没有本轮 BO3 进度、没有"下一场/本轮结束"，也没有第 3 场后的收尾。插件侧"最多 3 场"的规则在 UI 上无承接。
- **Why**：用户明确的成功路径是"每场回主界面结算，最多 3 场"；现在结算完只剩关闭，玩家不知道还能不能打、这是第几场。旅程在最高点断掉。
- **Fix**：结算卡加 `第 1/2/3 场` 三段进度、本轮比分、下一场按钮（≤2 场时）与「本轮结束」态（第 3 场）；关闭后回大厅并保留"本轮 BO3 · 2/3"卡片。
- **Suggested command**: `/impeccable onboard`

### [P1] 字号系统名存实亡

- **What**：732 条 font-size、36 个取值、`var(--fs-*)` 使用 **0 次**；<10px 共 112 条（9px×42、9.5×51、8.5×16、8×3）；半像素 311 条（42.5%）。
- **Why**：DESIGN.md 承诺 8 档、禁半像素；实际导航 12.5px（App.css:7082-7090）、成员组头 9px（:4451-4464）、品牌副标 8px（:7060-7070）。中文在 1100×760 糊成色块，低配玩家首先丢的是等级与状态。
- **Fix**：0.6.53 先清零 <10px；0.6.54 把 13/12/11/10 四档写成 utility 并替换 .5 值；`--fs-*` 要么启用要么删。
- **Suggested command**: `/impeccable typeset`

### [P2] 外壳在收税：10 个目的地、24% 的成员栏

- **What**：顶栏 7 项（TitleBar.jsx:23-31）＋左轨 3 项＝10 个目的地；成员栏 320px 占 1320 宽 24%（App.css:3973-3975）；1180 宽管理台直接丢栏（:4060-4061）；lobby1180 的"插件"被裁且无提示。
- **Why**：双导航要求用户自己建图；小窗口下被裁掉的恰好是"跟谁打"。成员栏被团队当标志，却在自家最小宽度消失。
- **Fix**：成员栏默认 56px 收起、hover/点击展开；左轨三项并进 hero 的当前地图卡；管理台在小宽度固定为顶部二级 tab。所有裁切改为可滚动或折叠，不留静默丢内容。
- **Suggested command**: `/impeccable layout`

### [P2] 橙色通胀与语义色泛滥

- **What**：选中态实心橙＋glow（:7097-7103）、CTA（:7509-7516）、chip、金币、待审 tag 全是橙；HUD 三个数字各占一语义色（:7408-7425）。首屏 8 处橙。
- **Why**：违反自家 One Voice Rule；橙色不再是"可行动"，而是"到处都亮"，玩家扫不到主按钮。
- **Fix**：选中改文字橙＋1px 下划线；HUD 回中性色（仅异常用红/黄）；每屏橙色元素 ≤3（1 主 CTA + 1 选中 + 1 状态）。
- **Suggested command**: `/impeccable quieter`

## Cognitive Load

- 每屏 ≥3 个并列入口（hero＋三卡＋表格），双导航要自行建图。
- 决策点 >4 选项：顶栏 7 项；服务器筛选 7 个 chip（"全部"出现两次）；管理台 9 个全关手风琴只有计数（AdminPanel.jsx:99）；约战表单 5 字段常驻展开，下方 3 行房间同时等决断。
- 首屏需要同时理解：金币、在线、公告、收藏服、排位、约战、房间表——7 个信息块无主次。

## Emotional Journey

登录：先读三行更新日志（LoginPage.jsx:170-180），进门先看公告，泄气。大厅：很美，但「开始游戏」把你从人群带走，从"有人"掉到"单人"。匹配成功：最高点——3 秒进游戏、双方座位、准备数（RankedPage.jsx:117-119）。结算：单场结果卡后直接关闭，没有"这一轮"的收尾，峰值后是空场。

## Persona Red Flags

**Alex（老玩家/权力用户）**：10 个目的地无命令面板；chip 不能组合筛选；收藏与直连语义重叠；右键改头衔不可发现。

**Jordan（第一次打开）**：以为「开始游戏」已经开赛，结果进空图；顶栏「设置」与头像 chip 同效；「不登录，直接进游戏」与「进入大厅」体量相当，没有理由选。

**阿凯（QQ 群 + FCX 绿包 + 1100×760）**：此宽度成员栏消失，恰好藏掉"跟谁打"；左轨「插件」被裁无提示；资源库把 `G:\FCX1\FCXT_02融合包` 当安装位置（AssetLibrary.jsx:443-449），他装 D 盘会以为出错；9px 徽章在 768p 不可读。
