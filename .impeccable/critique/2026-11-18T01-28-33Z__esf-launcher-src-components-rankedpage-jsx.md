## 设计特异性

**判定：60/40，外壳是作者性的，工作面是可互换的。**

深色舞台、琥珀行动、村民→破坏的十段命名、龙珠徽章、“距鹤仙传人还差 45 分”，这些话换任何产品都写不出来。可“我的战绩”仍是一张通用投注历史表：状态条 + N 行 + 计数胶囊；排行榜是头像/名字/数字/百分比，页面最可替换的物件。最强的品牌资产（会动的徽章）放在用户只看一次的 hero，而用户停留最久的战绩区，除一个文字标签外没有龙珠词汇。

v2 解决了整页滚动和空态裸露，但用“更多容器装饰”回应了“太空”，而不是用“更明确的内容”回应。

## 检测器证据

两个目标各跑一次 `detect.mjs`：`RankedPage.jsx` 与 `Lobby.jsx` 均 exit 0、0 findings。用临时文件注入 `bg-clip-text` + `from-purple-500` 自检，同一命令 exit 1 报 2 条，证明不是静默 no-op。检测器只做源码规则，看不到 App.css 级联后的真实字号、对比度与裁切，故以下 P0/P1 均来自渲染证据：

- **P0 读序破损**：`App.css:5330` 遗留 `.rank-history-main b{display:block;font-size:11px}` 命中战绩副行的对手名，名字独占一行；46px 固定高 + `overflow:hidden` 把“对手名 / 用时 / 时间”拆成上下两段。1344×795 与真机均复现。
- **P1 行盒溢出**：排行榜行 `App.css:16135` 压到 26px，名字 11px + 段位 9px × 1.5 行高 ≈ 30px，段位字下缘被下一行填充切掉。
- **P1 对比度 2.90:1**：未达段位标签 `.rank-step b` 用 `rgba(176,188,210,.46)`，合成色 (97,104,117) / 背景 (30,32,38) = 2.90:1，10px 文本低于 AA。
- **P1 字号坍缩**：20 个选择器 <10px，最低 7.5px（榜单胜率）、8px（AFK、规则）、8.5px（徽章提示、TOP 8）。中文 8–9px 不是小字，是纹理。
- **P2 内部滚动无提示**：战绩与榜单均为 overlay 滚动条，截图看不到第 6–8 行仍可滚。
- **P2 焦点**：`.rank-history-row` 是 button 但无作者态 `:focus-visible`；hover 的位移在键盘焦点下不复现。

## 总体印象

这是一个“拍照很好、审计很差”的页面。排位入口、天梯轨、徽章、结算卡已经形成完整的世界；真正拖住它的是身份数字自相矛盾、近看字号失焦、以及把一个本可以很锋利的战绩卡塞成了四个容器。最大的机会不是再加一块 UI，而是让“段位/名次/战绩”只有一个权威口径，然后把省下的空间还给内容。

## 立得住的

1. **天梯轨**：10 个有名字、有颜色、有“距下一段还差 N 分”的节点，是整页唯一无法被搬到别处的组件，承担了整张数据页的识别工作。
2. **战绩行本体**：胜/负、模式、地图、对手、用时、时间、±分、旧→新分，46px 内说清一场比赛；而且 +25−20+25−20+25 = +35，数据是算过的，不是摆上去的。
3. **单视口纪律**：取消整页滚动是对的；5 行战绩 + TOP 8 + 规则在 1344×795 内成立。

## 优先问题

### [P0] 段位身份在三个地方同时自相矛盾
**是什么**：真实数据里 hero 是天下拳王 900 分，榜单同一人是龟仙弟子 / 未定级，自己行第 8，footer 第 9；根源是 `ranked.js` 把 `matches=0`、默认 1000 分的资料也排进榜并计入名次，而客户端用 `rankOf(rating)` 显示段位、`matches ? 胜率 : 未定级` 显示状态。
**为什么重要**：段位是产品承诺本身。一处矛盾，整条天梯就变成装饰，用户会截图当笑话发群。
**修法**：榜单与名次只统计 `matches > 0`；0 场用户显示“未上榜/未定级”；footer 名次与列表渲染使用同一份快照；禁止页面里再用裸 `rating < x` 分支推断段位。
**建议命令**：/impeccable polish

### [P0] 战绩副行被遗留 CSS 拆行并裁切
**是什么**：`.rank-history-main b{display:block}` 让对手名独占一行，46px 行盒装不下三段信息。
**为什么重要**：每一行都错，且发生在用户看得最久的区域；读序从“对手 · 用时 · 时间”变成“对手 / 用时 · 时间”。
**修法**：把该规则收窄到 `.rank-history-line b`；给 `.rank-history-sub b` 显式 `display:inline; font-size:10.5px`；复核长 ID 省略号。
**建议命令**：/impeccable polish

### [P1] 字号塌到 7.5–9.5px，近看就“廉价”
**是什么**：榜单胜率 7.5px、规则与 AFK 8px、TOP 8/徽章提示 8.5px、时间与地图 9–9.5px；还有 12.5px 半像素。
**为什么重要**：最重要的竞技信号（胜率）是全页最不可读的字；中文 8px 已糊成灰块。
**修法**：执行 DESIGN 的 11/12/13/14/18/24/32 阶梯，删掉 7.5–10.5 区间；胜率、时间、规则、AFK 提到 10–11px；靠删内容而不是缩字重排。
**建议命令**：/impeccable typeset

### [P1] 空态用第二个实心主按钮换取“不空”，但仍空
**是什么**：393px 卡里约 220px 是空气，徽章被压到 62% 透明，卡内“开始第一场”与 hero“开始匹配”同为实心琥珀，180px 内两个主行动。
**为什么重要**：首访者不知道哪个才是“那个按钮”；徽章在唯一需要建立身份的时刻被调暗。
**修法**：徽章恢复 100% 并承诺“首场后点亮”；卡内 CTA 降为 ghost，hero 独占主行动；三个 01/02/03 改成真正的首场流程（排队 → 3 秒进服 → 写回段位），不再复述规则。
**建议命令**：/impeccable onboard

### [P2] “我的战绩”没有稳定口径
**是什么**：概览取 `history.slice(0,5)`，列表渲染 `history.map`（最多 10 行）藏在一个内滚框里；计数在“已记录 N 场/近 10 场”之间跳；“再打一场”在 `history.length < 10` 时消失。
**为什么重要**：同一张卡同时声称近 5 场、已记录 10 场，还能滚出第 6–10 行；最活跃的玩家反而失去唯一重复行动。
**修法**：明确“最近 5 场”并只渲染 5 行；计数说同一个数；footer 永久保留“再打一场”。
**建议命令**：/impeccable clarify

### [P2] 大厅约战卡把“开一间房”说了三遍，还新增第四个琥珀焦点
**是什么**：标题“约熟人开一间房” + 步骤 01“开一间房” + 按钮“开一间房”；按钮是设计系统外的浅橙 ghost，带 plus + chevron，却只是 `setPage('challenges')` 导航。
**为什么重要**：同屏大厅 pill、快速匹配、约战按钮都穿琥珀，行动色不再等于“唯一要做的事”；按钮承诺“开房”，点击却只换页。
**修法**：文案改成“约熟人开一场”，步骤 01 改成“选好赛制”，按钮改成“去开房”并只留 chevron；改用中性 ghost，不使用第四套琥珀。
**建议命令**：/impeccable polish

## 次要观察

1. `TOP 8` 与 `SEASON 1` 以 8–8.5px、0.12–0.22em 字距呈现，眉题规则自己的下限是 11px。
2. `.rank-history-row:hover` 横向位移 1px，读起来像抖动而非抬起；也没有 active 态。
3. “已记录 5 场”是琥珀描边/琥珀字/琥珀底的被动计数，违反 One Voice 对琥珀装饰的禁令。
4. 日期同列混用“今天 09:07”和“11-17 08:16”，没有“昨天”，也没有年份。
5. `.rank-history-afk` 8px：如果玩家被判 AFK（−30），整行最重的后果却是最小的字。
6. 段位一档三个名字：hero“鹤仙人”、chip“鹤仙”、段位名“鹤仙传人”，需统一为“鹤仙传人”。

## 三个问题

1. 如果徽章是签名，为什么在玩家最没有身份的时刻，它是全页唯一被调到 62% 的东西？一个锁住但全彩、写着“第一场后点亮”的徽章，是否比灰徽章更像承诺？
2. “我的战绩”一定要是列表吗？对天梯玩家更诚实的物件，是不是一条 5 场状态条（胜 胜 负 胜 负）+ 一个可展开复盘 + 一行连胜？
3. 如果这页要尊重一个输球的夜晚，它会多出什么——连胜/连败状态、“今晚最佳一局”、还是“再战同一对手”？现在它的情绪只有“中性”和“琥珀”，而竞技天梯需要第三种音区。

## 本次 polish 的范围

按 P0 → P1 → P2 修因不修果：统一段位/名次口径、修副行读序、把字号抬回 10–11px 地板、重排榜单单行高度、空态只留一个主行动、战绩口径收敛到最近 5 场、约战卡去掉重复与第四套琥珀。保留现有深色舞台、徽章、天梯轨与全部行为，不重做视觉世界。
