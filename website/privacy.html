隐私说明

适用范围：ESF China 平台（Electron 启动器、账号与排位后端、AMXX 游戏服插件）。本平台为小范围邀请制社区，非公开商业运营。最近更新：2026-11-11。

一句话说明：我们只保存「让平台能跑起来」所必需的账号与对局数据，不投放广告、不出售数据、不做用户画像。

1. 收集哪些信息

  • 账号：用户名、游戏昵称、密码哈希（bcrypt）、角色权限、头像、自定义状态与头衔。
  • 邮箱：仅在绑定邮箱 / 找回密码时提供，用于发送验证码；未绑定则不保存。
  • 登录与会话：登录时间、来源 IP、设备 UA、会话标识与撤销状态；登录失败次数用于锁定保护。
  • 游戏行为：在线时长、金币与流水、格斗等级、排位分数与胜负、约战房间与战绩、观战记录、竞猜下注。
  • 本地文件：启动器在本机保存设置、登录态（Windows DPAPI 加密）与启动日志；这些数据留在你的电脑上。

2. 用途

用于登录鉴权、找回密码与两步验证、一键连服的身份校验、排位/约战匹配与结算、金币结算、资源审核、公告下发以及故障排查。不用于广告投放、不向第三方出售或共享。

3. 存储、留存与安全

  • 数据存放在平台自建的 MySQL 中，MySQL 不对公网开放；公网入口由反向代理提供 HTTPS。
  • 数据库每日自动备份，保留 14 天，备份文件含个人信息，仅存放于受限目录，不进入公开仓库。
  • 密码只存哈希；登录态使用 JWT + 会话撤销；游戏服插件使用最小权限数据库账号，不接触密码哈希。
  • 运维审计日志会记录管理操作与来源 IP。

4. 第三方

  • QQ 邮箱 SMTP：仅用于发送邮箱验证码 / 找回密码邮件。
  • GitHub Releases：用于分发客户端安装包与更新元数据；下载行为由 GitHub 记录。
  • 平台本身不接入统计、广告或行为分析 SDK。

5. 删除与导出

账号可在管理台注销：会清空邮箱、密码与会话，保留历史对局记录以维持排位与战绩一致性。如需彻底删除或导出个人数据，请通过下节方式联系维护者，我们会人工处理并从备份轮换周期中一并清除。

6. 联系与漏洞报告

本平台开源仓库为 xiaolouxi123/esf-platform。隐私相关请求与安全问题请通过仓库维护者私信或 GitHub 的私密漏洞报告（Security Advisory）提交，不要公开 Issue；详见 SECURITY.md。

7. 其他

  • 客户端安装包未做代码签名，Windows SmartScreen 会提示；请只从官网给出的 GitHub Releases 链接下载并核对版本。
  • 本平台基于 Half-Life / ESF 模组，与游戏版权方无关联；仅限小范围社区内部使用。
