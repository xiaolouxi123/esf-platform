ESF 平台 · 服务器部署包
========================

包含：
  deploy.bat                 ← 双击这个（右键“以管理员身份运行”）
  deploy-esf-server.ps1      部署脚本
  esf-server-bundle.zip      后端代码

使用步骤
--------
1. 把这个压缩包复制到服务器（远程桌面里直接复制粘贴文件即可）
2. 解压到任意目录，例如 C:\Users\Administrator\Desktop\esf-deploy
3. 右键 deploy.bat → 以管理员身份运行
4. 等待脚本自动完成：
   - 下载并安装 Node.js 18
   - 下载并安装 MySQL 8.0（端口 3307，仅本机）
   - 部署后端、建库建表
   - 注册 Windows 服务 ESFAPI
   - 防火墙放行 3000
   首次下载约 250MB，视网速 5~20 分钟
5. 看到 “后端已在本机健康运行” 即成功

成功后必须手动做
----------------
腾讯云控制台 → 安全组 / 防火墙 → 入站规则：
  协议 TCP，端口 3000，来源 0.0.0.0/0

然后浏览器访问：
  http://114.132.84.150:3000/api/health
应返回 {"ok":true,...}

最后回到对话告诉我：部署脚本跑完了 + 安全组已放行 3000

出问题看哪里
------------
  服务状态： services.msc → ESFAPI / ESFMySQL
  后端日志： C:\esf\logs\api.err.log
  更新目录： C:\esf\updates
  凭据文件： C:\esf\CREDENTIALS.txt（保存后删除）

注意
----
- 脚本可重复运行，已存在的 .env 和数据会保留
- 如果 3307 端口被占用，脚本会停止并提示
- MySQL 数据目录：C:\esf\mysql-data，不要随意删除
