## 这轮已改

### 1. 数据真实性：分页与全库统计

- 前端首屏 `PAGE_SIZE = 100`，`loadMore()` 用 offset 追加并按 id 去重；加载完隐藏「加载更多」。
- 服务端 `GET /assets` 新增全库统计：
  - `SELECT a.kind, COUNT(*) ... GROUP BY a.kind`
  - `SELECT COUNT(DISTINCT author_id) ...`
- 响应新增 `stats.counts / totalDownloads / authorCount`，前端 HUD、类型胶囊、底部计数优先用 `stats`。
- 错误态不再显示 0：HUD 显示 `—`，底部显示「统计不可用」；空态和错误态分离。
- 已验证：mock 137 条 → 首屏 100 条、HUD 137、点「加载更多」后 137 条并隐藏按钮；线上 API 返回真实 `stats`。

相关：`esf-launcher/src/components/AssetLibrary.jsx:128`、`:152`、`:225`；`server/src/routes/assets.js:316`、`:319`、`:336`。

### 2. 安装闭环：回执、已安装、更新、恢复

- 新增本地回执 `asset-receipts.json`（`store.cjs:234` 起）：记录 id、slug、name、version、targetPath、bytes、backedUp、installedAt。
- 安装成功后写回执；资源库用回执显示「已安装 / 有更新 / 重装 / 更新到 vX」。
- 新增 `assets:receipts`（`main.cjs:2034`）按当前模组目录计算文件是否存在、备份是否还在。
- 新增 `assets:restore`（`main.cjs:2053`）从 `.esf-backup` 恢复安装前原文件；右侧出现「恢复安装前的原文件」。
- 安装仍是 sha256 校验 + 首次备份，不重复堆备份。

相关：`esf-launcher/main.cjs:1984`、`:2016`、`:2034`、`:2053`；`store.cjs:251`、`:261`。

### 3. 交互与可访问性

- 新增 `SelectMenu.jsx`：深色 listbox，替换排序与上传类型两处原生 select（Windows 白底蓝选中问题消失）；支持方向键、Home/End、Enter/Space、Esc、点击外部关闭、焦点回到触发器。
- 资源列表改 roving tabindex：只有当前行和它的安装按钮进入 Tab 顺序；`ArrowUp/Down/Home/End` 切换行并移动焦点，100 行不会变成 200 个 Tab 停点。
- 上传弹层：Esc/焦点陷阱保留；关闭后焦点回到「上传资源」触发按钮，不再回到排序按钮。
- 搜索框命中区从 18px 提到 34px；显示清除按钮；focus-within 有琥珀环。
- 取消文件选择不再静默，提示「已取消选择文件」。

相关：`SelectMenu.jsx:8`；`AssetLibrary.jsx:264`、`:290`。

### 5. 诚实性修正

- 之前 `other` 允许 `.zip`，但安装只写单文件、不解压，UI 仍报「已安装」——这是假承诺。
- 本轮先移除 `.zip` 上传入口（前端/主进程/服务端三处），避免用户上传整包后得到一个没解压的 zip 文件。
- 整包能力没有消失，而是明确留到 P0 的下一版：见下文。

## 对比成熟平台

| 能力 | ESF 当前 | 成熟平台（Steam Workshop / Thunderstore / Nexus / ModDB） | 影响 |
|---|---|---|---|
| 包模型 | 单文件单路径 | 一个包含模型、贴图、配置、依赖清单 | **P0**：真实模型包装不完整 |
| 版本与依赖 | 单版本号 | manifest、requirements、版本约束、依赖解析 | 装错版本/缺依赖会静默坏 |
| 安装状态 | 已安装/有更新/恢复 | 订阅状态、文件清单、卸载、校验修复 | 已有回执，但无卸载与完整性修复 |
| 作者生命周期 | 只能上传新资源 | 编辑、发新版本、下架、变更日志 | 作者改一次就要重新建条目 |
| 发现与信任 | 搜索/类型/排序 | 标签、合集、评分、评论、举报、精选 | 内容一多就找不到 |
| 传输 | 单次整包下载 | CDN、断点续传、分片、镜像 | 64MB 上限与弱网友好度不足 |
| 运营 | 管理员审核 | 审核队列、推荐位、合集、赛季专题 | 有审核接口，但缺运营工具 |
| 客户端安装 | 写文件 + 备份 | 冲突检测、文件归属、卸载/回滚 | 多资源改同一路径会互相覆盖 |

结论：ESF 的「大厅 + 账号 + 比赛」是强项，资源库目前是**单文件下载器**，不是包管理器。要追平，不需要抄全部社交功能，先把「包、版本、安装状态」三件事做对。
