## 一、为什么暂缓

0.6.59 因漏打包 `esf-launcher/archive.cjs` 启动即崩，0.6.60 已修复并上线。资源库的多文件安装、卸载、恢复链路在自动化层已通过，但以下行为必须在真实 Windows 整合包和真人操作下确认，模拟环境不能替代：

1. 0.6.58 及更早版本自动更新到 0.6.60；
2. 0.6.59 用户手动覆盖安装到 0.6.60；
3. 真实 FCX 模型包（.mdl + 贴图 + txt）上传 → 审核 → 另一台机器安装 → 进游戏确认模型和贴图都正确；
4. 安装后卸载、恢复安装前原文件，游戏仍能正常启动；
5. 最小窗口 1180×780、真实网络延迟下的资源库操作。

在完成上述项目之前，0.6.60 只能记为“自动化与模拟验证通过，真人验收未执行”。
