# ESF Platform 0.4.0

发布日期：2026-11-04

## 重点

- 排位天梯：1v1 单排、2v2 双人组队
- 快速匹配、座位准备、3 秒倒计时进入比赛
- 比赛服务器锁定，非参赛玩家无法进入
- 金币：在线 1/分钟，游戏 2/分钟
- 格斗等级与新手房限制
- 托盘：开游戏自动隐藏，退出游戏自动恢复
- 游戏中切换服务器 / 本地开图自动重启
- 单机组队 / 混战切换（mp_gamemode 2 / 0）
- 频道、成员名单、头衔、自定义头像
- 竞猜与排行榜
- AMXX：2v2 自动检测、队伍 HUD、比赛结果回写、结束 5 秒 quit

## 更新方式

启动器会通过 `/updates/latest.yml` 自动更新，也可以直接运行安装包覆盖安装。

## 注意

- 当前安装包未做代码签名，Windows SmartScreen 可能提示
- 线上服务器需要同步 AMXX 插件与数据库迁移
