P9 · 频道页

把重复的标题删掉，把垂直空间还给消息

一句话：频道不是另一个应用，是停在大厅里聊天。 标题从三处减到一处，聊天卡去掉重复的卡头，输入框修到卡内——多出来的 40px 全给消息列表。

01

改了四个地方

  • 页头收成一行：返回大厅做成 28px 胶囊；# 大厅频道 17px + 一条说明；右侧「全服公开」换成带绿点的胶囊
  • 去掉重复的卡头：页面已经有标题，聊天卡里那句「大厅频道 / 公开可见」就删了；欢迎块标题改成「欢迎来到大厅频道」，不再和页头撞名
  • 消息与输入区：头像 26、名字 12 + 角色标 9、时间 10.5、正文 12.5/1.62；自己发的那条带 5% 橙底；输入框 36 高，发送钮 36 方块——之前它会顶到卡片右缘被裁掉，现在是 input flex:1 0 0 + 按钮 flex:0 0 36px
  • 整页高度：.channel-page 改 flex 列 + card--chat{flex:1}，消息列表撑满、输入框钉在卡底
02

为什么这样改

  1. 标题原来重复三次（页头、卡头、欢迎块），读起来像三个页面拼在一起；同一个名字只该出现一次。
  2. 聊天最缺的是垂直空间。 去掉 40px 的卡头，等于多显示一条半消息；1180 高度下这一条很实在。
  3. 输入框以前会溢出。 按钮被卡片右缘裁掉一角，原因是输入框没设 flex-basis:0，按钮又是定宽；现在两者都收进 12px 内边距里。
  4. 和大厅共用一套语汇：卡片是面板、绿点是状态、胶囊是标签，频道不再像另一个产品。
03

代码落点

可以看到的东西：标题只剩一处、输入框与发送钮都在卡内、自己的消息有橙底、1180 宽不漏边；发消息、轮询、错误提示这些逻辑没动。
