# ESF 平台 UI 设计规范 v2（0.6.53 提案）

> 适用范围：`esf-launcher/`（Electron + React 启动器）与同源管理台。
> 关系：`DESIGN.md` 记录「现在是什么」（现状规范化），本文档定义「下一版应该是什么」（目标规范）。两者冲突时以本文档为准，落地后回写 DESIGN.md。
> 概念稿：`shots/redesign-v3.html`（全站 12 屏可点原型，含插件/频道/地图抽屉/设置抽屉），截图 `shots/v3/01-lobby.png` … `shots/v3/11-settings.png`，小屏验证 `shots/v3/12-lobby-1366.png`。v2 保留作历史。

## 0. 一句话方向

**把「大厅」从信息墙改成一张开赛台：一个主动作、一条比赛状态机、一份结算回执。**

现有界面不缺氛围，缺的是「我现在该点哪里」的确定性。所有页面都堆了 5–8 个同权重入口，橙色的按钮出现 3 次以上，玩家要在公告、金币、在线数、收藏服、排位卡、约战卡之间自己拼出下一步。

### 评审结论（/impeccable critique，2026-11-18）

- 综合 25/40。最严重的不是配色，是**主 CTA 语义错**：大厅最大的橙色按钮「开始游戏」绑定本地开图，把玩家送进单人空图，真实对局只是表格里的小按钮。
- 其次是**结算缺一轮的收尾**：结果卡只有单场比分与 rating 变化，没有 BO3 第几场、下一场、本轮结束。
- 再次是**字号系统失效**：732 条 font-size、0 次使用 `--fs-*`、112 条 <10px、311 条半像素。
- 完整报告：`.impeccable/critique/2026-11-17T20-57-19Z__esf-launcher-src-app-css.md`。

## 1. 五条结构主张

1. **一屏一个主动作。** 大厅唯一主 CTA 是「快速匹配 1v1」；约战是次级 ghost 按钮；金币/在线数只出现在顶栏一处，正文不再重复。
2. **比赛状态机常驻。** `idle → 匹配中 → 已找到 → 准备 → 进游戏 → 结算` 六态共用一张「开赛卡」，在同一位置变形，不跳页、不弹窗打断。匹配成功是全屏唯一允许的强提示。
3. **结算优先。** BO3 每场结束回主界面：结算卡给比分、积分变化、金币、下一场/退出。最多 3 场，第 3 场结束只给「本轮结束」，不自动续排。
4. **双层导航。** 顶栏＝产品域（大厅/排位/约战/服务器/资源库/管理台/设置）；左侧 rail＝当前域内的工具（当前地图/频道/插件）；右侧成员栏常驻、可折叠。三层各司其职，不互相复制入口。
5. **收敛优先于新增。** 不引入新组件库、不加新页面；先把字号、色值、圆角、阴影、弹层收敛到 token，再谈新功能。

## 2. 外壳与布局

| 区域 | 尺寸 | 规则 |
|---|---|---|
| 顶栏 | 64px | 品牌 196px · 导航胶囊 · 右侧状态条（在线/金币合一）· 头像 · 窗口键 |
| 状态条 | 28px | 左：连接/延迟/服务器数；右：版本号 + 帮助。**禁止出现开发地址**（`http://127.0.0.1:3000`） |
| 左侧 rail | 64px | 52×52 磁贴，3 个入口 + 底部在线数/帮助 |
| 成员栏 | 300px（折叠 56px） | 头衔分组、在线点、角色色；行高 44px |
| 内容区 | 1fr | 左右 14px 内边距，卡片间距 12px |

主设计尺寸 1322×901；**必须完整适配 1366×768**（社区最常见笔记本分辨率）：顶栏 56 + 状态条 26 + 内容区全部落在 768 内，状态条永远贴底，整页不出现竖向滚动。最小窗口 1120×700，低于该宽度只允许横向滚动，不允许裁切。布局用 `height:100vh` + 三行 grid，内容区自身 `overflow:auto`；`@media (max-height:830px)` 收紧 hero（120px）、按钮高度（32/27）、表格行距（6/14）。

**顶栏右侧只保留一个状态胶囊**：`● 4 台在线 · 12 人 · 1,762 金币`。金币与在线数不再以 chip 形式出现在正文。

## 3. 页面规范

### 3.1 登录 / 注册

- 结构：左侧品牌宣言（标题 54px，两行；三条能力 bullet），右侧 420px 认证卡。
- 主动作：进入大厅（橙色，44px 高，全宽）。
- 次级：不登录直接进游戏（ghost）；注册 / 忘记密码（文字链）。
- 公告条：最多两行，超出省略号 + 「展开」；不得挤压输入框。
- 版本号只在状态条右下角出现一次；登录卡内不重复。
- 错误：字段下方 12px 红字，直接显示服务端 `details[0].message`；输入框描边转红，不同时弹 toast。

### 3.2 大厅

三段，从上到下（原型：`pageLobby()` + `matchDeck()`）：

1. **Hero（176px，768 高时收到 120px）**：左侧品牌宣言 + 一行元信息（当前地图 · 版本 · BO3 结算 · 换地图）；右侧「今晚」数据块（台数/人数/平均延迟/金币）+ 两个按钮：主「快速匹配」、次「本地对局」。Hero 的主 CTA **只指向真实对局**；本地开图不是被删除，而是降级为次级入口（见 3.10）。
2. **开赛台 / 双卡（约 120px）**：idle 时是两张并排卡——左「排位卡」（C 徽章 · 1180 · 进度条 · 12 场 7 胜 5 负 · 排行榜 / 战绩与 BO3），右「约战卡」（一句说明 + 三个 chip：BO3 / 允许观战 / 不计分 + 「开一间房」）。匹配中 / 已找到 / 已准备时整行切换成一张全宽状态卡（进度环 → VS 卡 → 倒计时），不弹窗、不跳页。
3. **房间表**：4 行必须在一屏内可见，列＝房间/延迟/人数/模式/加入；离线行降饱和 + 「离线」文字，按钮禁用。
4. 右栏成员面板常驻 300px（头衔分组、在线点、角色色、搜索）；战绩不再单独占首页。

公告、最近上架收进底部一行，点击展开抽屉。

### 3.3 结算（BO3）

- 触发：每场比赛结束后自动弹出；不做整页跳转。
- 结构（560px）：结果徽标（胜利/失败）· 比分 · 本轮进度 `第 2 / 3 场` · 双方 rating 前后值与 ±delta · 金币变化。
- 动作：≤2 场时给「下一场」（primary）与「本轮结束」；第 3 场后只给「本轮结束」（primary）与「查看战绩」。
- 关闭后回大厅，开赛台保留「本轮 BO3 · 2/3 · 已结算」卡片，可点开重看。
- 禁止：结算卡自动续排；禁止关闭后静默回队列。

### 3.4 排位

- 左 320px 段位卡：徽章 96px、分数 34px、进度条、胜负/胜率、开始排位 + 排行榜。
- 右：最近战绩表（结果徽标 / 对手 / 比分 / 时间），每行 44px，最多 5 行 + 查看全部。
- 本轮 BO3 进度条（第 1/2/3 场：已结算 / 进行中 / 待开始）常驻段位卡下方。
- 匹配中：开赛台替换为进度环 + 已等待时长 + 取消；不跳转页面。

### 3.5 约战

- 两种入口并列：**开房**（主）与**加入房间**（列表）。
- 开房流程 3 步一屏完成：模式（1v1/2v2）→ 规则（地图/回合/观战）→ 确认。默认值必须可直接开。
- 房间卡：房主/模式/人数/状态（等待/准备/进行中）；等待中显示邀请码与「复制邀请语」（给 QQ 群用）。
- 开战后与排位共用开赛卡与结算卡，不另做一套。

### 3.6 服务器

- 顶部一行统计（在线/人数/平均延迟）+ 添加服务器。
- 筛选 chips：全部模式/单挑/新手/组队 · 在线/收藏。
- 表格列：房间（名 + IP + 地图）/ 延迟 / 人数 / 模式 / 加入。房名以管理台注册名为准，实时名作副标题。
- 我的服务器与直连查询降为底部两个次要区块。

### 3.7 资源库

- 三列：缩略图 46px · 两行信息（名称/类型/版本 + 路径/作者/大小/下载）· 操作（安装/更新）。
- 右侧安装位置卡：MOD DIR 路径、按类型列出落点、备份说明。
- 上传入口固定在标题行右侧；审核状态用 chip 标在名称后。

### 3.8 管理台

- 手风琴改为「左二级导航 + 右内容」两栏：服务器/格斗等级/玩家/频道头衔/运营/注册与邀请/资源审核/占用看板。
- 每个面板第一行是摘要（数量 + 一句状态），展开后是表格；表格行 44px，操作列固定右侧。
- 危险操作（踢人/删除/封禁）必须二次确认，确认文案写出对象名。

### 3.9 设置

- 抽屉 480px，8 个分区手风琴，默认只展开「游戏目录」。
- 分区标题 13px/600，描述 11px；保存按钮固定在底部，脏值提示。
- 游戏目录：自动寻找 + 选择目录并排；显示找到的 hl.exe 与 esf 模块路径；失败给具体原因（未找到 FCX 目录 / 权限不足）。

### 3.10 本地对局（弹层，三处入口共用）

- 入口：① hero 次级按钮「本地对局」；② 地图抽屉底部「本地开图」；③ 约战页「本地对局」卡。三处都调同一个 `openLocal()`，不允许各写一套。
- 结构（560px）：标题「本地对局」+ 一句说明「单机练习、本地开房都在这里，不经过匹配，不计分」；地图 select（12 张全量，不按筛选裁剪）；模式分段（单人练习 / 本地开房）；玩家数（单人固定 1+1，开房 2–8）；随机出生点开关；底部一句「本地对局会以 X 启动 hl.exe，平台留在后台，Esc 退出对局回大厅。联机身份校验不生效」。
- 动作：取消（ghost）/ 启动本地对局（primary）。
- 为什么不是首页主 CTA：本地开图把玩家送进一张空图，等于把「平台」降级成「启动器」；单机需求真实存在，但应由玩家显式选择，而不是默认动作。

### 3.11 插件中心（左轨入口，不是弹窗）

线上现状（`PluginsPage.jsx`）只有三块 HUD（本地插件 0/4、当前服务器 离线、心跳 —）+ 一张警告卡，右栏 2/3 空白，且 mock 的 `plugins.status` 只有 path/enforce/dir、没有 `observe`，页面长期停在空态。规范改为：

- **Hero**：标题「插件中心」；右侧两格 = 「4 / 4 与服务端一致」+「3 分钟前 最近心跳」，第三行 chip 显示当前服务器名；不放第三个 HUD 格（三格在 1366 下必挤）。
- **本地插件表（左 2/3，必须有 4 行）**：文件名 + 描述 / 大小 / 版本 / 状态 chip（与服务端一致 / 仅本地 / 缺失）。表头右侧显示插件目录绝对路径。没有 4 行就说明加载失败，不能只显示「0/4」。
- **平台心跳卡**：服务器 / 构建 / 插件数 / 下次上报 ≤60 秒，并解释「只有接了 platform_auth 的服务器才会亮；无心跳时显示『无心跳』而不是『未知』」。
- **诊断卡**：最近 10 行日志 + 「查看完整日志」按钮（弹层，720px，等宽字体）。
- **运行配置卡**：AMXX 目录、配置文件、平台身份校验开关（关掉后不校验 token，仅建议本地测试）、打开目录 / 复制路径。
- 面板只读：任何开关都不改写服务器 `amxx.cfg`，只在本地配置层生效，文案必须写清。

### 3.12 大厅频道（左轨入口）

- 三栏：消息流（1fr）· 频道信息卡（240px）· 成员面板（常驻）。
- 顶栏：`# 大厅频道` + 一句定位「全服玩家实时聊天 · 组队、约战、反馈都在这里」+ 在线 chip。
- 消息流：欢迎卡（三条规则 chip）→ 标签筛选（全部/组队/约战/反馈）+「刷新间隔 6 秒」→ 消息行（头像/昵称/角色 chip/时间/标签，自己的消息整行高亮）。
- 频道信息卡：可见范围 / 发言权限 / 刷新间隔 / 保留条数；下方「在线的人」与「快捷指令」（/who、/ip、/report）。
- 输入框常驻底部，Enter 发送、Shift+Enter 换行；发送后立即本地插入再等服务端回执。
- 只有一条公开频道是现状，不假装有多频道；但保留标签筛选，避免以后加频道时重做。

### 3.13 地图抽屉（左轨触发，392px）

- 顶部：标题「地图库」+ 数量 chip + 关闭 ×；搜索框（地图名 / 代号）。
- 筛选：全部 / 对战 / 生存 / 剧情 / 收藏（星标）。
- 列表行 56px：缩略图（56×36，无图时用首字占位）、中文名 + 代号 · 模式 · 人数、右侧星标。
- 底部固定：当前地图名 + 主按钮「本地开图」（调 3.10 弹层）。
- 抽屉打开时左侧 rail 仍可见（不遮导航）；Esc 关闭；点遮罩关闭。
- 选中地图只改「下一局默认地图」并给 toast，不直接启动游戏。

## 4. 组件规范

| 组件 | 尺寸 | 状态 | 备注 |
|---|---|---|---|
| Button | 36 高（sm 30，lg 42） | default / hover / active / focus-visible / disabled / loading | 主按钮全站每屏 ≤1 个 |
| Icon Button | 32×32 | 同上 | 必须有 aria-label |
| Input | 42 高，圆角 11 | default / focus / error / disabled | placeholder 对比度 ≥4.5:1（当前 #4f5468 仅 2.53，必须改） |
| Select | 36 高 | 同上 | 原生 select 样式化，不用自绘下拉 |
| Chip | 24 高，圆角 7 | default / active / disabled | 只做筛选，不做导航 |
| Switch | 38×22 | on / off / focus | 点击区 ≥44×44（外层 padding 补足） |
| Card | 圆角 16，padding 16 | default / hover（可点） | 玻璃只用于浮层与 hero，不再叠在普通卡片上 |
| Modal | 420 / 560 / 720 宽 | open / closing | 见第 6 节 |
| Drawer | 420 / 480 宽 | 同上 | 设置、公告、战绩详情 |
| Toast | 320 宽，右下 16 | ok / error / info | 3.5s 自动消失，可手动关 |
| Tooltip | 12px 文本 | hover / focus | 仅补充信息，不承载唯一入口 |
| Table | 行 44–56，表头 10px 大写字距 | hover / selected / empty | 表头不换行 |
| Empty | 图标 28 + 一句 + 一个动作 | — | 禁止只写「暂无数据」 |

字号只用四档：**13（正文/按钮）/ 12（次要）/ 11（说明）/ 10（标签下限）**。标题 18/24/32。现存 8–9.5px 共 112 处必须在 0.6.53 清零。

## 5. 动效规范

| 场景 | 时长 | 曲线 |
|---|---|---|
| hover / 颜色 | 120ms | ease-out |
| 按下 | 90ms | ease-out |
| 面板/抽屉 | 180ms | cubic-bezier(.2,.8,.2,1) |
| 页面切换 | 180ms 淡入 + 4px 上移 | ease-out |
| 匹配成功 | 240ms 弹入 + 1 次 1.2s 呼吸光 | ease-pop |
| 结算数字 | 400ms 计数 | ease-out |
| Toast | 180ms 滑入 | ease-out |

规则：

- 只动 `transform` 与 `opacity`；不动 width/height/top/left（现有 3 处 layout transition 必须改）。
- 匹配成功与结算允许一次强提示；其余不加发光、不加弹跳。
- 「减少动效」开关与 `prefers-reduced-motion` 同时生效：所有动画降到 0.01ms，保留状态变化。
- 音效：点击/切页/匹配成功/结算四类；总开关关闭后静音，不静默播放。

## 6. 弹层规范

- **只有一套 Modal**：遮罩 `rgba(5,7,11,.62)` + blur 6px；面板 `--panel` + 1px `--line` + `--el-3`；圆角 16。
- 尺寸：420（确认）/ 560（表单）/ 720（列表/详情）。宽度不超过窗口 92%。
- 关闭：Esc、点遮罩、右上 ×。**匹配成功卡不允许点遮罩关闭**，只能「取消对局」。
- 焦点：打开时焦点进第一个可操作元素；Tab 循环限制在面板内；关闭后焦点回触发按钮。
- 层级：drawer 40 · modal 60 · toast 80 · tooltip 90。现有 z-index 出现 120 与 -1，需归并。
- 危险确认：标题写动作（「踢出 天野雪辉？」），正文写后果，主按钮红色，默认焦点在取消。
- 不允许嵌套弹层；需要二级信息时用抽屉或页内展开。

---

## 7. 状态、文案与可访问性

- 加载：骨架屏 ≥300ms 才显示，避免闪；按钮 loading 保持宽度不变。
- 空：说明为什么空 + 一个可行动作（「还没有房间，开一个」）。
- 错：一句话说清 + 重试按钮；不展示堆栈与英文错误码。
- 离线：整行降饱和 + 「离线」文字，不只靠颜色。
- 可访问性底线：所有可点元素是 `button`/`a` 或带 `role+tabIndex+onKeyDown`；`:focus-visible` 全站统一 3px 橙色光晕；成员行、房间行必须键盘可达；`aria-modal` + `aria-labelledby` 用在所有弹层。

## 8. 落地顺序

**0.6.53（P0，1–2 天）**
1. 大厅主 CTA：hero 主按钮改「快速匹配」，本地开图降为次级「本地对局」→ 3.10 弹层（地图抽屉底部与约战页同源）。
2. 大厅：删重复金币/在线 chip，开赛台 / 排位卡 / 约战卡三态合一（idle / 匹配中 / 已找到）。
3. 结算卡：BO3 三场进度 + 每场回主界面 + 第 3 场结束态。
4. 字号：8/8.5/9/9.5px 全部抬到 10px；placeholder 对比度改到 4.5:1。
5. 状态条去掉 `http://127.0.0.1:3000`。
6. 外壳适配 1366×768：`height:100vh` 三行 grid + `max-height:830px` 断点，状态条贴底、整页不竖滚。
