P7 · 设置与登录

抽屉分成七张卡，登录页的公告收成两行

一句话：这是两个「不常来但必须清楚」的界面。 设置抽屉从一条长滚动分成七张卡、保存条固定在底部；登录页把越来越长的版本公告收成两行，想读再展开。

01

改了三个地方

  • 设置抽屉：470 宽、左圆角 18；头部 14px 标题 + 关闭靠右；游戏目录 / 服务器插件 / 平台连接 / 音效 / 账号安全 / 账号 / 关于 各自成卡（圆角 16、1px 边、12×14 内边距）；输入与选择统一 32px 高，说明文字 10.5px；底部「取消 / 保存」固定在抽屉底部
  • 登录页：卡片收到 388 宽，字段 40 高、主按钮 40 高；公告条默认两行（超过 46 字才出现「展开」），展开后完整显示、按钮变「收起」
  • 同一档控件高度：设置 32、登录 40、上传面板 32，鼠标落点和视觉重量一致
02

为什么这样改

  1. 设置是「一次性配置」，不是浏览。 七张卡 + 固定的保存条，让人一眼分清「改哪一项」和「改没改」；一条长滚动里，保存按钮会跟着内容跑。
  2. 公告会随版本变长。 它现在有六行，把输入框顶到卡片下半截；默认两行、按需展开，既保留信息又不动布局。
  3. 控件高度是跨页的约定。 前面几页把输入框定在 32–40 之间，这两页跟着走，不再出现「这一页 44、那一页 28」。
  4. 不改结构与逻辑。 抽屉还是抽屉（导航、头像、左下齿轮三个入口都能开），登录还是原来那个表单和找回密码流程；改动集中在 CSS 和一处展开状态。
03

代码落点

可以看到的东西：七张分区卡、固定保存条、登录卡尺寸、公告两行与展开按钮，截图里都能核对；保存、登录、找回密码这些流程本身没动。
