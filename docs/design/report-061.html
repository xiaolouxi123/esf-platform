建议下一阶段

  • P0 验收：你与朋友打一局 1v1/2v2，把上面 4 项走一遍；发现的问题我按「先模拟再发包」修。

  • P2 稳定性：并发登录/配置拉取压测、24 小时 soak、备份恢复演练、ops agent 自愈（中文输出与 RDP 依赖）。
06

这轮学到的坑

  • 插件 SELECT 列序写错（5 当 mode，实际 7），2v2 永远被当 1v1——列序必须与 SQL 一起 review。
  • 结算绝不能走 JS 版 finishMatch（会绕过 AFK −30），必须 CALL settle_ranked_match。
  • ranked_match_players.slot 是 NOT NULL，模拟数据要补 slot。
  • Caddy 计划任务没有触发器，11/7 起静默宕机——已加 ESFCaddyWatch 每 5 分钟自愈。
  • npm run dev 看不到改动：安装版单实例锁 + 残留 vite 占 5173；用 npm run dev:test。
